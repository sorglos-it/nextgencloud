# NGC Plan 4: Datenbank – Umsetzungsplan

> **Für ausführende Agenten:** PFLICHT-SUBSKILL: `superpowers:subagent-driven-development`
> (empfohlen) oder `superpowers:executing-plans`, Aufgabe für Aufgabe. Die Schritte sind Kästchen
> (`- [ ]`). Gearbeitet wird auf Branch `db`, Pull Request nach `main`.

**Ziel:** `dbapi` (Vertrag V4) läuft zweimal: auf einem MariaDB-Galera-Verbund aus drei Knoten mit
TLS gegen die CA der Installation und auf einer mit AES-256-XTS verschlüsselten SQLite-Datei. Beide
bestehen dieselben Konformitätstests aus `shared/dbapi/dbtest`, der Verbund verkraftet den Ausfall
eines Knotens, und eine nummerierte Migration läuft, während die vorige API-Version weiterarbeitet.

**Aufbau:** Eine einzige Umsetzung von `dbapi` in portablem SQL (`classes/sqlstore/`) bedient beide
Datenbanken; was sich unterscheidet, steckt hinter einer kleinen Schnittstelle `Dialect`
(Spaltentypen, Fehlerdeutung, Tabellennachsatz). Darüber liegen nur noch zwei dünne Pakete, die
die Verbindung herstellen: `classes/mariadb/` (TLS je Knoten, Lastverteilung, Ausweichen,
Wiederholen) und `classes/sqlite/` (verschlüsselt öffnen). Das Schema kommt ausschließlich aus den
nummerierten Migrationen in `sql/`, die `classes/migrate/` einspielt. Der Verbund selbst und die
CA der Installation entstehen im ulh-Skript `ngc-db.sh`; die Vorlagen dafür und ihre Prüfungen
liegen hier.

**Technik:** Go 1.27 mit `database/sql`, `github.com/go-sql-driver/mysql` v1.10.1 und
`github.com/ncruces/go-sqlite3` v0.35.5 mit `vfs/xts` (beide liegen schon in `vendor/`). MariaDB
mit Galera und `file_key_management` (AES-256) aus den Paketquellen von Debian und Ubuntu,
`openssl` für die CA der Installation, `mariadb-dump` für die Sicherung.

**Entwurf:** [`docs/superpowers/specs/2026-09-19-ngc-kern-design.md`](../specs/2026-09-19-ngc-kern-design.md),
Abschnitt 4.6 („Datenbank“) und 4.8 („Updates“).
**Anweisungen:** [`apps/server-db/CLAUDE.md`](../../../apps/server-db/CLAUDE.md).

## Verbindliche Vorgaben

Aus `CLAUDE.md` im Stamm, `apps/server-db/CLAUDE.md` und `shared/README.md`. Sie gelten für jede
Aufgabe, auch wo eine Aufgabe sie nicht wiederholt.

- **Verträge sind eingefroren.** Nichts in `shared/` wird angefasst. Was eine Änderung bräuchte,
  steht unten unter „Offene Entscheidungen für den Koordinator“.
- **Go 1.27**, Bau für linux/amd64 und linux/arm64 mit `CGO_ENABLED=0`; deshalb SQLite ohne cgo.
- **`tools/check.sh` muss vor jedem Commit grün sein** (gofmt, `go vet`, `go test ./...`, Bau für
  beide Architekturen mit `-tags modules`). Auf Linux zusätzlich `go test -race ./...`.
- **Beide Umsetzungen bestehen dieselben Tests**: `dbtest.Run` aus `shared/dbapi/dbtest`, ohne
  Ausnahme und ohne eigene Abwandlung.
- **SQL nur mit Platzhaltern.** Jede Anweisung ist eine Go-Konstante; Tabellen- und Spaltennamen
  kommen nur aus den festen Listen in `classes/sqlstore/names.go`. Nichts wird zur Laufzeit
  zusammengesetzt. Der MariaDB-Treiber läuft mit `InterpolateParams = false`, der Server sieht also
  nie einen Wert im Anweisungstext.
- **Jede Eingabe wird geprüft, bevor sie in eine Anweisung geht**: Typ, Länge, erlaubte Werte
  (`classes/sqlstore/limits.go`). Beide Datenbanken lehnen dasselbe ab, damit die Konformitätstests
  auf beiden gleich ausgehen.
- **MariaDB nur über TLS**, geprüft gegen die CA der Installation mit `config.DB.TLSConfig(host)`
  und dem Host des Knotens aus `db.nodes` als Servername. Keine Verbindung ohne Prüfung, kein
  Rückfall auf Klartext (`AllowFallbackToPlaintext = false`).
- **SQLite verschlüsselt** mit AES-256-XTS (`vfs/xts`, 64-Byte-Schlüssel aus `config.DB.Key`).
- **Geheimnisse nie ins Log**, auch nicht gekürzt. Passwörter und Schlüssel kommen nur über
  `config.SecretText.Text()` bzw. `config.Secret.Bytes()` und gehen direkt in den Treiber. In
  Fehlermeldungen steht nie eine Verbindungszeichenkette.
- **Knotenadressen** sind `<host>:<port>` nach `trust.ValidHostPort`, höchstens `config.MaxField`
  lang; geprüft hat sie schon `config.DB.Validate()`, der Code verlässt sich nicht darauf, sondern
  zerlegt sie mit `net.SplitHostPort`.
- **Portables SQL:** nur, was MariaDB, SQLite, MySQL, MSSQL und Oracle verstehen. IDs erzeugt die
  Anwendung, Zeitstempel sind Zahlen, keine datenbankeigenen Funktionen, kein `AUTO_INCREMENT`,
  kein `ON DUPLICATE KEY`, kein `MERGE`, kein `IF NOT EXISTS`, kein `FOR UPDATE`. Die einzigen
  Stellen, die sich unterscheiden dürfen, sind die Spaltentypen und der Tabellennachsatz; sie
  kommen aus einer festen Tabelle je Datenbank.
- **Kein Test legt ein Schema von Hand an.** Jeder Test spielt die Migrationen ein.
- **Erst Tests, dann Code** (TDD): erst den fehlschlagenden Test schreiben, laufen lassen,
  fehlschlagen sehen, dann die kleinste Umsetzung, dann grün sehen, dann committen.
- **Kleine Commits**, englische Nachricht in der Befehlsform, jeder Commit mit dem Trailer
  `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.
- **Sprache:** Code, Bezeichner, Kommentare und Commit-Nachrichten Englisch; dieser Plan, Dokumente
  und Meldungen für Benutzer Deutsch. Kommentare erklären, warum etwas so ist.
- **Aufbau nach dem Projektstruktur-Standard:** `apps/server-db/` mit `VERSION`, `classes/`,
  `sql/`, `templates/` und `config/` (nur `*.example`). Kein eigenes Programm, keine neuen
  Ordnernamen.
- **Code aus diesem Plan nach dem Einfügen mit `gofmt -w` formatieren.** Abweichungen bei
  Einrückung sind kein Planfehler.

package sqlstore

import (
	"slices"
	"strings"
	"testing"
)

// TestNames guards the rule "table and column names only from fixed lists":
// every name is a plain lower-case identifier, short enough for Oracle's
// 30 characters, and none is a word one of the five databases reserves.
func TestNames(t *testing.T) {
	for _, table := range Tables {
		cols, ok := Columns[table]
		if !ok || len(cols) == 0 {
			t.Errorf("table %q has no columns", table)
		}
		checkIdent(t, table)
		for i, c := range cols {
			checkIdent(t, c)
			if slices.Contains(cols[:i], c) {
				t.Errorf("table %q names column %q twice", table, c)
			}
		}
	}
	if len(Columns) != len(Tables) {
		t.Errorf("Columns has %d tables, Tables %d", len(Columns), len(Tables))
	}
}

func checkIdent(t *testing.T, s string) {
	t.Helper()
	switch {
	case s == "" || len(s) > 30:
		t.Errorf("%q: 1 to 30 bytes", s)
	case s[0] < 'a' || s[0] > 'z':
		t.Errorf("%q: must start with a letter", s)
	case strings.Trim(s, "abcdefghijklmnopqrstuvwxyz0123456789_") != "":
		t.Errorf("%q: only a-z, 0-9 and _", s)
	case slices.Contains(reserved, strings.ToUpper(s)):
		t.Errorf("%q is reserved in one of the five databases", s)
	}
}

// TestFill checks that a migration is filled from the dialect's table only.
func TestFill(t *testing.T) {
	got, err := Fill(MariaDB, "CREATE TABLE ngc_lock (name {{key}} NOT NULL, until {{int}} NOT NULL){{opts}}")
	want := "CREATE TABLE ngc_lock (name VARBINARY(255) NOT NULL, until BIGINT NOT NULL) ENGINE=InnoDB ROW_FORMAT=DYNAMIC"
	if err != nil || got != want {
		t.Errorf("MariaDB: %q, %v; want %q", got, err, want)
	}
	if got, err := Fill(SQLite, "a {{key}} b {{int}}{{opts}}"); err != nil || got != "a BLOB b INTEGER" {
		t.Errorf("SQLite: %q, %v", got, err)
	}
	for _, bad := range []string{"x {{blob}}", "x {{}}", "x {{ key }}", "x {{key"} {
		if _, err := Fill(MariaDB, bad); err == nil {
			t.Errorf("%q was accepted", bad)
		}
	}
}

// Package sqlstore implements dbapi.Store on database/sql in SQL that
// MariaDB, SQLite, MySQL, MSSQL and Oracle all understand. Only the column
// types and the suffix of CREATE TABLE differ; they come from a Dialect.
package sqlstore

import (
	"fmt"
	"strings"
)

// Tables are every table NGC uses, in the order 0001 creates them. Nothing
// outside this list is ever named in a statement.
var Tables = []string{
	"ngc_schema", "ngc_lock", "ngc_blob", "ngc_app", "ngc_once",
	"ngc_user", "ngc_session", "ngc_pending", "ngc_log",
}

// Columns are the columns of each table, in the order of the CREATE TABLE.
var Columns = map[string][]string{
	"ngc_schema":  {"version", "step", "done", "applied"},
	"ngc_lock":    {"name", "owner", "until"},
	"ngc_blob":    {"kind", "id", "seq", "data", "updated"},
	"ngc_app":     {"id", "version", "store", "node", "active", "manifest", "sha256", "grants", "kept_data", "updated"},
	"ngc_once":    {"kind", "token", "data", "expires", "used"},
	"ngc_user":    {"id", "name", "roles", "totp", "locked", "failures", "last_login"},
	"ngc_session": {"token", "user_id", "cert", "proof", "api_key", "api_cert", "created", "expires", "seen"},
	"ngc_pending": {"pubkey", "name", "since"},
	"ngc_log":     {"id", "ts", "user_id", "kind", "app", "action", "node", "result_code", "detail"},
}

// Placeholders are the names a migration may use for a column type. A
// migration writes {{key}}; Fill puts the dialect's type in its place.
var Placeholders = []string{"key", "text", "doc", "data", "int", "opts"}

// reserved holds the words the five databases reserve, upper case. The list
// is why columns are called user_id, ts and result_code: "user", "time" and
// "result" are reserved somewhere. It is not the full standard, only what a
// name of ours could realistically hit. "action" is deliberately not in it:
// none of the five reserves it, and the column of a log entry is called that
// in the contract too (core.LogEntry.Action).
var reserved = []string{
	"ADD", "ALL", "ALTER", "AND", "AS", "ASC", "AUDIT", "BETWEEN", "BY", "CASE", "CHECK",
	"COLUMN", "COMMENT", "COMMIT", "CREATE", "CURRENT", "CURRENT_DATE", "CURRENT_TIME",
	"CURRENT_TIMESTAMP", "CURRENT_USER", "DATE", "DEFAULT", "DELETE", "DESC", "DISTINCT", "DROP",
	"ELSE", "END", "EXISTS", "FILE", "FOR", "FROM", "GRANT", "GROUP", "HAVING", "IN", "INDEX",
	"INSERT", "INTO", "IS", "KEY", "LEVEL", "LIKE", "LOCK", "LONG", "MODE", "NOT", "NULL", "NUMBER",
	"OF", "OFFSET", "ON", "OPTION", "OR", "ORDER", "PASSWORD", "PRIMARY", "PUBLIC", "RAW", "RENAME",
	"RESOURCE", "REVOKE", "ROW", "ROWID", "ROWNUM", "ROWS", "SELECT", "SESSION", "SET", "SHARE",
	"SIZE", "START", "SYSDATE", "TABLE", "THEN", "TIME", "TIMESTAMP", "TO", "TRIGGER", "UID",
	"UNION", "UNIQUE", "UPDATE", "USER", "VALIDATE", "VALUES", "VARCHAR", "VIEW", "WHEN", "WHERE",
	"WITH",
}

// Fill puts the dialect's column types into a migration statement. An
// unknown or malformed placeholder is an error, so a typo in a migration
// never reaches the database.
func Fill(d Dialect, stmt string) (string, error) {
	var b strings.Builder
	for {
		i := strings.Index(stmt, "{{")
		if i < 0 {
			b.WriteString(stmt)
			return b.String(), nil
		}
		b.WriteString(stmt[:i])
		rest := stmt[i+2:]
		j := strings.Index(rest, "}}")
		if j < 0 {
			return "", fmt.Errorf("sqlstore: placeholder without end in %q", stmt)
		}
		name := rest[:j]
		typ := d.Type(name)
		if typ == "" && name != "opts" {
			return "", fmt.Errorf("sqlstore: unknown placeholder %q", name)
		}
		b.WriteString(typ)
		stmt = rest[j+2:]
	}
}

```go
package sqlstore

import (
	"errors"

	"github.com/go-sql-driver/mysql"
	"github.com/ncruces/go-sqlite3"
)

// Dialect is everything that differs between the databases behind the same
// SQL: the column types of a migration and the meaning of a driver error.
type Dialect interface {
	// Type returns the column type for a placeholder of a migration, or ""
	// for one it does not know. "opts" may return "".
	Type(placeholder string) string
	// Retry reports whether err is a conflict that rolled the statement
	// back, so the caller may run the whole operation again unchanged: a
	// Galera certification conflict, a lock that waited too long, SQLite's
	// "busy". It is never true for an error that may have committed.
	Retry(err error) bool
	// Duplicate reports whether err is a broken primary key or unique index.
	Duplicate(err error) bool
	// Exists reports whether err says a table, index or column is already
	// there, which a migration that runs a second time after a crash sees.
	Exists(err error) bool
	// Gone reports whether err means the connection failed, so a read may be
	// repeated, possibly on another node.
	Gone(err error) bool
	// DDLInTx reports whether CREATE and ALTER can live in a transaction.
	// MariaDB commits them on its own, SQLite does not.
	DDLInTx() bool
}

// MariaDB is the dialect of MariaDB and MySQL.
var MariaDB Dialect = mariaDialect{}

// SQLite is the dialect of SQLite.
var SQLite Dialect = sqliteDialect{}

type mariaDialect struct{}

func (mariaDialect) Type(p string) string {
	switch p {
	case "key":
		return "VARBINARY(255)"
	case "text":
		return "VARBINARY(1024)"
	case "doc":
		return "MEDIUMBLOB"
	case "data":
		return "LONGBLOB"
	case "int":
		return "BIGINT"
	case "opts":
		// InnoDB is what Galera replicates; DYNAMIC keeps long keys usable.
		return " ENGINE=InnoDB ROW_FORMAT=DYNAMIC"
	}
	return ""
}

// MariaDB error numbers, https://mariadb.com/kb/en/mariadb-error-codes/.
const (
	errDupEntry     = 1062 // duplicate value for a key
	errDupKeyName   = 1061 // index is already there
	errDupColumn    = 1060 // column is already there
	errTableExists  = 1050 // table is already there
	errLockWait     = 1205 // lock wait timeout, rolled back
	errDeadlock     = 1213 // deadlock; Galera reports a certification conflict here
	errWsrepAborted = 1047 // node is not ready to serve, the transaction is gone
)

func mysqlNumber(err error) uint16 {
	var e *mysql.MySQLError
	if errors.As(err, &e) {
		return e.Number
	}
	return 0
}

func (mariaDialect) Retry(err error) bool {
	n := mysqlNumber(err)
	return n == errDeadlock || n == errLockWait || n == errWsrepAborted
}

func (mariaDialect) Duplicate(err error) bool { return mysqlNumber(err) == errDupEntry }

func (mariaDialect) Exists(err error) bool {
	n := mysqlNumber(err)
	return n == errTableExists || n == errDupKeyName || n == errDupColumn
}

func (mariaDialect) Gone(err error) bool {
	// A driver error without a MariaDB number is a broken connection: the
	// server never answered. Only a read is repeated after it.
	return err != nil && mysqlNumber(err) == 0 &&
		(errors.Is(err, mysql.ErrInvalidConn) || errors.Is(err, mysql.ErrPktSync) || isNetwork(err))
}

func (mariaDialect) DDLInTx() bool { return false }

type sqliteDialect struct{}

func (sqliteDialect) Type(p string) string {
	switch p {
	case "key", "text", "doc", "data":
		return "BLOB"
	case "int":
		return "INTEGER"
	case "opts":
		return ""
	}
	return ""
}

func (sqliteDialect) Retry(err error) bool {
	return errors.Is(err, sqlite3.BUSY) || errors.Is(err, sqlite3.LOCKED)
}

func (sqliteDialect) Duplicate(err error) bool {
	return errors.Is(err, sqlite3.CONSTRAINT_PRIMARYKEY) || errors.Is(err, sqlite3.CONSTRAINT_UNIQUE)
}

// Exists: SQLite runs its DDL inside the transaction, so a migration never
// sees half of itself again.
func (sqliteDialect) Exists(error) bool { return false }

func (sqliteDialect) Gone(err error) bool { return errors.Is(err, sqlite3.IOERR) }

func (sqliteDialect) DDLInTx() bool { return true }
```

func isNetwork(err error) bool {
	var ne net.Error
	return errors.As(err, &ne) || errors.Is(err, io.EOF) || errors.Is(err, syscall.ECONNRESET) ||
		errors.Is(err, syscall.ECONNREFUSED) || errors.Is(err, syscall.EPIPE)
}

```go
package sqlstore

import (
	"strings"

	"github.com/sorglos-it/nextgencloud/shared/dbapi"
	"github.com/sorglos-it/nextgencloud/shared/store"
)

// The bound of every column kind. Go checks each value before it goes into a
// statement, so both databases refuse the same input: MariaDB would cut or
// complain, SQLite would take anything, and the conformance tests have to
// come out the same on both.
const (
	MaxKey  = 255      // every {{key}} column: IDs, names, kinds, tokens, hashes
	MaxText = 1024     // every {{text}} column: owner of a lock, detail of a log entry
	MaxDoc  = 1 << 20  // every {{doc}} column: manifest, certificates, keys, lists
	MaxData = 80 << 20 // Blob.Data: store.MaxUITotal (64 MiB) plus the tar headers
	MaxList = 256      // entries of User.Roles or App.Grants (trust allows 256 roles)
	MaxItem = 64       // one entry of such a list (wire.ValidName is at most 32)
)

func okKey(s string) bool  { return len(s) <= MaxKey }
func okText(s string) bool { return len(s) <= MaxText }
func okDoc(b []byte) bool  { return len(b) <= MaxDoc }
func okData(b []byte) bool { return len(b) <= MaxData }

// blob keeps a nil slice out of the driver: a nil []byte binds as NULL, and
// every column is NOT NULL.
func blob(b []byte) []byte {
	if b == nil {
		return []byte{}
	}
	return b
}

// joinList packs a short list of names into one column, separated by a line
// feed. Every entry a contract allows here (roles: wire.ValidName, grants:
// store.NeedRoot and store.NeedNetwork) is printable without line breaks, so
// the separator can never appear inside an entry; joinList refuses anything
// else instead of writing something splitList could not take apart.
func joinList(list []string) (string, bool) {
	if len(list) > MaxList {
		return "", false
	}
	for _, s := range list {
		if s == "" || len(s) > MaxItem || strings.ContainsAny(s, "\n\r") {
			return "", false
		}
	}
	return strings.Join(list, "\n"), true
}

// splitList takes a column written by joinList apart. An empty column is an
// empty list, never a list with one empty entry.
func splitList(s string) []string {
	if s == "" {
		return nil
	}
	return strings.Split(s, "\n")
}

// checkSeq guards Blob.Seq: it is a uint64 in the contract, but no unsigned
// 64-bit column exists in all five databases, so everything above the signed
// range is refused instead of wrapping around.
func checkSeq(seq uint64) error {
	if seq > 1<<63-1 {
		return dbapi.ErrInvalid
	}
	return nil
}

// grantsOK reports whether every grant is one the contract knows; an app
// carries at most store.NeedRoot and store.NeedNetwork.
func grantsOK(list []string) bool {
	for _, g := range list {
		if g != store.NeedRoot && g != store.NeedNetwork {
			return false
		}
	}
	return true
}

// Package sqlite opens the encrypted SQLite file of NGC: the database of a
// controller, and the one that stands in for MariaDB when everything runs on
// one Pi. The file is encrypted with AES-256-XTS, so a copy of it is worth
// nothing without the key from the configuration.
package sqlite

import (
	"database/sql"
	"encoding/hex"
	"errors"
	"fmt"
	"net/url"
	"strings"

	"github.com/ncruces/go-sqlite3"
	sqlitedriver "github.com/ncruces/go-sqlite3/driver"
	_ "github.com/ncruces/go-sqlite3/embed"    // the SQLite build the driver runs
	_ "github.com/ncruces/go-sqlite3/vfs/xts"  // registers the encrypting VFS "xts"

	"github.com/sorglos-it/nextgencloud/shared/config"
)

// busyTimeout is how long a writer waits for another one before it gives up
// with "busy"; the store repeats such an operation itself.
const busyTimeout = 10000 // milliseconds

// OpenDB opens the file named by cfg, encrypted with cfg.Key. It does not
// create any table: the schema comes from the migrations.
func OpenDB(cfg config.DB) (*sql.DB, error) {
	if cfg.Driver != config.DriverSQLite {
		return nil, fmt.Errorf("sqlite: driver %q, want %q", cfg.Driver, config.DriverSQLite)
	}
	key := cfg.Key.Bytes()
	if len(key) != 64 {
		return nil, errors.New("sqlite: the key must be 64 bytes for AES-256-XTS")
	}
	// The key is the only value that ever reaches SQL as text instead of as a
	// placeholder, because PRAGMA takes no placeholder. hex.EncodeToString of
	// 64 bytes is always 128 characters of 0-9 and a-f, so there is nothing in
	// it that could end the string or add a statement.
	hexkey := hex.EncodeToString(key)
	dsn, err := fileURL(cfg.Path)
	if err != nil {
		return nil, err
	}
	db, err := sqlitedriver.Open(dsn, func(c *sqlite3.Conn) error {
		// Order matters: the key first, because everything after it reads the
		// file. Temporary files stay in memory so that no part of the data
		// lands on disk with a random key instead of ours.
		for _, pragma := range []string{
			"PRAGMA hexkey='" + hexkey + "'",
			fmt.Sprintf("PRAGMA busy_timeout=%d", busyTimeout),
			"PRAGMA journal_mode=wal",
			"PRAGMA synchronous=normal",
			"PRAGMA temp_store=memory",
			"PRAGMA foreign_keys=on",
		} {
			if err := c.Exec(pragma); err != nil {
				return err
			}
		}
		return nil
	})
	if err != nil {
		return nil, err
	}
	// A handful of connections is plenty for one controller or one Pi, and it
	// keeps the memory of the SQLite build small. Writers take the file lock
	// one after another; busy_timeout and the store's repeat handle the wait.
	db.SetMaxOpenConns(4)
	db.SetMaxIdleConns(4)
	return db, nil
}

// fileURL turns the path of the configuration into the data source name.
// Building it with net/url escapes the path, so a path that holds a "?" can
// never add a URI parameter of its own - "?hexkey=00" would otherwise put a
// key of the attacker's choosing next to ours.
func fileURL(path string) (string, error) {
	if !strings.HasPrefix(path, "/") || len(path) > config.MaxField {
		return "", errors.New("sqlite: the path must be absolute")
	}
	u := url.URL{Scheme: "file", Path: path, RawQuery: "vfs=xts&_txlock=immediate"}
	return u.String(), nil
}
```

`_txlock=immediate` steht dabei, damit eine Schreib-Transaktion die Sperre schon beim Beginn nimmt.
Sonst holt SQLite sie erst beim ersten Schreiben und zwei Transaktionen, die beide zuerst lesen,
können sich gegenseitig blockieren, statt zu warten.

```go
package migrate

import (
	"errors"
	"fmt"
	"slices"
	"strings"

	"github.com/sorglos-it/nextgencloud/apps/server-db/classes/sqlstore"
)

// forbidden are the words a migration may never carry. Some are not portable
// (IF NOT EXISTS, AUTO_INCREMENT, ENGINE), the others would break the promise
// that the previous API version keeps working while the migration runs: it
// still reads the tables and columns it knows.
var forbidden = []string{
	"DROP", "RENAME", "TRUNCATE", "AUTO_INCREMENT", "IF NOT EXISTS", "IF EXISTS",
	"ENGINE=", "SERIAL", "IDENTITY", "GENERATED", "CURRENT_TIMESTAMP", "NOW(", "MERGE ",
}

// errOnlyAdd says what the rule is in one sentence the author can act on.
var errOnlyAdd = errors.New("a migration may only add: no DROP, RENAME or TRUNCATE, because the previous API version keeps running")

// checkStatement checks one statement of a migration.
func checkStatement(s string) error {
	if strings.Contains(s, ";") {
		return fmt.Errorf("a statement holds a semicolon: %.40q", s)
	}
	// No string literal at all: every value goes in as a placeholder, and
	// without quotes the splitter never has to understand quoting.
	if strings.ContainsAny(s, "'\"`") {
		return fmt.Errorf("a statement holds a quote: %.40q", s)
	}
	upper := strings.ToUpper(s)
	for _, w := range forbidden {
		if strings.Contains(upper, w) {
			if w == "DROP" || w == "RENAME" || w == "TRUNCATE" {
				return fmt.Errorf("%w: %.40q", errOnlyAdd, s)
			}
			return fmt.Errorf("%q is not portable: %.40q", w, s)
		}
	}
	for _, p := range placeholdersIn(s) {
		if !slices.Contains(sqlstore.Placeholders, p) {
			return fmt.Errorf("unknown placeholder %q: %.40q", p, s)
		}
	}
	return checkNames(s)
}

// checkNames refuses every word that looks like a table or column of ours but
// is in neither fixed list. It is deliberately blunt: a word starting with
// ngc_ has to be a listed table or an index named after one, and every bare
// lower-case word inside the brackets has to be a column of that table.
func checkNames(s string) error {
	table := ""
	for _, w := range words(s) {
		if !strings.HasPrefix(w, "ngc_") {
			continue
		}
		switch {
		case slices.Contains(sqlstore.Tables, w):
			table = w
		case table != "" && strings.HasPrefix(w, table+"_"):
			// an index of that table, for example ngc_blob_seq
		default:
			return fmt.Errorf("%q is in no fixed list: %.40q", w, s)
		}
	}
	if table == "" {
		return fmt.Errorf("a statement names no table: %.40q", s)
	}
	for _, w := range columnWords(s) {
		if !slices.Contains(sqlstore.Columns[table], w) {
			return fmt.Errorf("column %q is not listed for %q", w, table)
		}
	}
	return nil
}

// placeholdersIn returns the names between {{ and }}.
func placeholdersIn(s string) []string {
	var out []string
	for {
		i := strings.Index(s, "{{")
		if i < 0 {
			return out
		}
		s = s[i+2:]
		j := strings.Index(s, "}}")
		if j < 0 {
			return out
		}
		out, s = append(out, s[:j]), s[j+2:]
	}
}

// words returns every bare word of a statement, case kept.
func words(s string) []string {
	return strings.FieldsFunc(s, func(r rune) bool {
		return !(r == '_' || r >= 'a' && r <= 'z' || r >= 'A' && r <= 'Z' || r >= '0' && r <= '9')
	})
}

// keywords are the bare words inside the brackets that are not columns.
var keywords = []string{"not", "null", "primary", "key", "unique", "add", "column"}

// columnWords returns the words a statement uses as columns: every bare
// lower-case word inside the brackets that is not a keyword, a placeholder or
// a table name, plus the column of an ALTER TABLE ... ADD COLUMN.
func columnWords(s string) []string {
	var out []string
	if open := strings.Index(s, "("); open >= 0 {
		for _, w := range words(s[open:]) {
			lower := strings.ToLower(w)
			if w != lower || slices.Contains(keywords, lower) || strings.HasPrefix(lower, "ngc_") ||
				slices.Contains(sqlstore.Placeholders, lower) {
				continue
			}
			out = append(out, lower)
		}
	}
	f := strings.Fields(s)
	for i, w := range f {
		if strings.EqualFold(w, "COLUMN") && i+1 < len(f) {
			out = append(out, strings.ToLower(f[i+1]))
		}
	}
	return out
}

// belong to the version of ngc-api and travel inside its release file: one
// controller with role db runs them before the new API starts, and the
// installation runs them once.
package migrate

import (

// File is one migration: its number, its file name and its statements in
// order.
type File struct {
	Version    int64
	Name       string
	Statements []string
}

// List reads every migration and checks it against the rules. A migration
// that breaks one is an error, so a wrong file never reaches a database.
func List() ([]File, error) {
	entries, err := migrations.Files.ReadDir(".")
	if err != nil {
		return nil, err
	}
	var out []File
	for _, e := range entries {
		name := e.Name()
		if e.IsDir() || path.Ext(name) != ".sql" {
			continue
		}
		number, _, ok := strings.Cut(name, "-")
		version, err := strconv.ParseInt(number, 10, 64)
		if !ok || err != nil || version < 1 || len(number) != 4 {
			return nil, fmt.Errorf("migrate: %q is not named 0001-<name>.sql", name)
		}
		body, err := migrations.Files.ReadFile(name)
		if err != nil {
			return nil, err
		}
		stmts, err := split(string(body))
		if err != nil {
			return nil, fmt.Errorf("migrate: %s: %w", name, err)
		}
		out = append(out, File{Version: version, Name: name, Statements: stmts})
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Version < out[j].Version })
	for i, f := range out {
		if f.Version != int64(i+1) {
			return nil, fmt.Errorf("migrate: migration %d is missing", i+1)
		}
	}
	return out, nil
}

// split cuts a migration into statements. A statement ends at a semicolon;
// checkStatement refuses quotes, so a semicolon can never sit inside a value.
// A line that starts with -- is a comment.
func split(body string) ([]string, error) {
	var keep []string
	for _, line := range strings.Split(body, "\n") {
		if t := strings.TrimSpace(line); t != "" && !strings.HasPrefix(t, "--") {
			keep = append(keep, line)
		}
	}
	var out []string
	for _, raw := range strings.Split(strings.Join(keep, "\n"), ";") {
		stmt := strings.Join(strings.Fields(raw), " ")
		if stmt == "" {
			continue
		}
		if err := checkStatement(stmt); err != nil {
			return nil, err
		}
		out = append(out, stmt)
	}
	return out, nil
}

// lockName is the row of ngc_lock that keeps two servers from migrating at
// the same time, and lockFor is how long one run may hold it.
const (
	lockName = "migrate"
	lockFor  = 900 // seconds
)

// The runner's own two tables. They are not in 0001, because the runner needs
// them before the first migration can run. ngc_lock is the same table
// dbapi.LockTake uses later, taken the same way, so the two never disagree
// about who holds a lock.
const (
	createSchema = "CREATE TABLE ngc_schema (version {{int}} NOT NULL, step {{int}} NOT NULL, " +
		"done {{int}} NOT NULL, applied {{int}} NOT NULL, PRIMARY KEY (version)){{opts}}"
	createLock = "CREATE TABLE ngc_lock (name {{key}} NOT NULL, owner {{text}} NOT NULL, " +
		"until {{int}} NOT NULL, PRIMARY KEY (name)){{opts}}"
	probeSchema = "SELECT version FROM ngc_schema WHERE version = ?"
	probeLock   = "SELECT owner FROM ngc_lock WHERE name = ?"
	selectState = "SELECT step, done FROM ngc_schema WHERE version = ?"
	selectLevel = "SELECT version FROM ngc_schema WHERE done = ? ORDER BY version DESC"
	insertState = "INSERT INTO ngc_schema (version, step, done, applied) VALUES (?, ?, ?, ?)"
	updateStep  = "UPDATE ngc_schema SET step = ? WHERE version = ?"
	updateDone  = "UPDATE ngc_schema SET step = ?, done = ?, applied = ? WHERE version = ?"
	takeLock    = "UPDATE ngc_lock SET owner = ?, until = ? WHERE name = ? AND (owner = ? OR until <= ?)"
	insertLock  = "INSERT INTO ngc_lock (name, owner, until) VALUES (?, ?, ?)"
	freeLock    = "DELETE FROM ngc_lock WHERE name = ? AND owner = ?"
)

// Apply runs every migration that has not run yet and returns how many it
// ran. owner names who runs it (a node ID) and shows up in the lock, so an
// admin can see which server is migrating.
func Apply(ctx context.Context, db *sql.DB, d sqlstore.Dialect, owner string, now int64) (int, error) {
	files, err := List()
	if err != nil {
		return 0, err
	}
	if err := bootstrap(ctx, db, d); err != nil {
		return 0, err
	}
	taken, err := take(ctx, db, owner, now)
	if err != nil {
		return 0, err
	}
	if !taken {
		return 0, errors.New("migrate: another server is running the migrations")
	}
	defer func() {
		if _, err := db.ExecContext(ctx, freeLock, []byte(lockName), []byte(owner)); err != nil {
			slog.Warn("Die Sperre für die Migrationen ließ sich nicht freigeben.", "fehler", err)
		}
	}()
	done := 0
	for _, f := range files {
		ran, err := applyOne(ctx, db, d, f, now)
		if err != nil {
			return done, fmt.Errorf("migrate: %s: %w", f.Name, err)
		}
		if ran {
			done++
		}
	}
	return done, nil
}

// bootstrap makes sure the runner's own tables are there. It probes first,
// because CREATE TABLE IF NOT EXISTS is not portable: a probe that works
// means the table is there.
func bootstrap(ctx context.Context, db *sql.DB, d sqlstore.Dialect) error {
	for _, pair := range []struct {
		probe, create string
		arg           any
	}{
		{probeSchema, createSchema, int64(0)},
		{probeLock, createLock, []byte(lockName)},
	} {
		rows, err := db.QueryContext(ctx, pair.probe, pair.arg)
		if err == nil {
			rows.Close()
			continue
		}
		stmt, err := sqlstore.Fill(d, pair.create)
		if err != nil {
			return err
		}
		if _, err := db.ExecContext(ctx, stmt); err != nil && !d.Exists(err) {
			return err
		}
	}
	return nil
}

// take takes the migration lock the same way dbapi.LockTake does.
func take(ctx context.Context, db *sql.DB, owner string, now int64) (bool, error) {
	res, err := db.ExecContext(ctx, takeLock, []byte(owner), now+lockFor, []byte(lockName), []byte(owner), now)
	if err != nil {
		return false, err
	}
	n, err := res.RowsAffected()
	if err != nil {
		return false, err
	}
	if n > 0 {
		return true, nil
	}
	// Nothing changed: either the lock is held by somebody else, or there is
	// no row yet. The INSERT tells the two apart.
	if _, err := db.ExecContext(ctx, insertLock, []byte(lockName), []byte(owner), now+lockFor); err != nil {
		return false, nil
	}
	return true, nil
}

// applyOne runs one migration. SQLite keeps its DDL inside a transaction, so
// the whole file goes in at once. MariaDB commits every CREATE on its own,
// so each statement is recorded as it succeeds and a crash picks up there; a
// statement that ran but was not recorded fails with "already there", which
// the dialect knows and the runner steps over.
func applyOne(ctx context.Context, db *sql.DB, d sqlstore.Dialect, f File, now int64) (bool, error) {
	step, done, err := state(ctx, db, f.Version)
	if err != nil {
		return false, err
	}
	if done {
		return false, nil
	}
	if step == 0 {
		if _, err := db.ExecContext(ctx, insertState, f.Version, int64(0), int64(0), int64(0)); err != nil && !d.Duplicate(err) {
			return false, err
		}
	}
	if d.DDLInTx() {
		tx, err := db.BeginTx(ctx, nil)
		if err != nil {
			return false, err
		}
		defer tx.Rollback()
		for _, raw := range f.Statements {
			stmt, err := sqlstore.Fill(d, raw)
			if err != nil {
				return false, err
			}
			if _, err := tx.ExecContext(ctx, stmt); err != nil {
				return false, err
			}
		}
		if _, err := tx.ExecContext(ctx, updateDone, int64(len(f.Statements)), int64(1), now, f.Version); err != nil {
			return false, err
		}
		return true, tx.Commit()
	}
	for i, raw := range f.Statements[step:] {
		stmt, err := sqlstore.Fill(d, raw)
		if err != nil {
			return false, err
		}
		if _, err := db.ExecContext(ctx, stmt); err != nil && !d.Exists(err) {
			return false, err
		}
		if _, err := db.ExecContext(ctx, updateStep, step+int64(i)+1, f.Version); err != nil {
			return false, err
		}
	}
	_, err = db.ExecContext(ctx, updateDone, int64(len(f.Statements)), int64(1), now, f.Version)
	return true, err
}

// state returns how far a migration got: how many statements are recorded and
// whether it finished.
func state(ctx context.Context, db *sql.DB, version int64) (int64, bool, error) {
	var step, done int64
	switch err := db.QueryRowContext(ctx, selectState, version).Scan(&step, &done); {
	case errors.Is(err, sql.ErrNoRows):
		return 0, false, nil
	case err != nil:
		return 0, false, err
	}
	return step, done == 1, nil
}

// Level returns the highest migration that finished, 0 while none did.
func Level(ctx context.Context, db *sql.DB) (int64, error) {
	rows, err := db.QueryContext(ctx, selectLevel, int64(1))
	if err != nil {
		return 0, err
	}
	defer rows.Close()
	if !rows.Next() {
		return 0, rows.Err()
	}
	var version int64
	if err := rows.Scan(&version); err != nil {
		return 0, err
	}
	return version, rows.Err()
}

import (
	"context"
	"database/sql"
	"errors"
	"math/rand/v2"

	"github.com/sorglos-it/nextgencloud/shared/dbapi"
)

// maxTries is how often an operation is repeated after a conflict that rolled
// it back, and pause is how long the first wait is; it doubles, with a little
// noise so that two servers do not keep colliding in step.
const (
	maxTries = 8
	pause    = 2 * time.Millisecond
)

type store struct {
	db *sql.DB
	d  Dialect
}

// New returns dbapi.Store on an open database. It creates nothing: the schema
// comes from the migrations.
func New(db *sql.DB, d Dialect) dbapi.Store { return &store{db: db, d: d} }

func (s *store) Close() error { return s.db.Close() }

// write runs fn in one transaction and repeats the whole of it while the
// database says the transaction was rolled back: a Galera certification
// conflict (two nodes wrote the same row at once), a lock that waited too
// long, SQLite's "busy". An error that may have been committed is never
// repeated, because repeating it could turn a success into ErrUsed.
func (s *store) write(ctx context.Context, fn func(tx *sql.Tx) error) error {
	var err error
	for try := range maxTries {
		if try > 0 && !wait(ctx, try) {
			return ctx.Err()
		}
		var tx *sql.Tx
		if tx, err = s.db.BeginTx(ctx, nil); err != nil {
			if s.d.Retry(err) || s.d.Gone(err) {
				continue
			}
			return err
		}
		if err = fn(tx); err != nil {
			tx.Rollback()
			if s.d.Retry(err) {
				continue
			}
			return err
		}
		if err = tx.Commit(); err == nil {
			return nil
		}
		if !s.d.Retry(err) {
			return err
		}
	}
	return err
}

// exec runs one statement, which needs no transaction of its own, and returns
// how many rows it matched. It repeats the statement on the same conflicts as
// write.
func (s *store) exec(ctx context.Context, stmt string, args ...any) (int64, error) {
	var err error
	for try := range maxTries {
		if try > 0 && !wait(ctx, try) {
			return 0, ctx.Err()
		}
		var res sql.Result
		if res, err = s.db.ExecContext(ctx, stmt, args...); err != nil {
			if s.d.Retry(err) {
				continue
			}
			return 0, err
		}
		return res.RowsAffected()
	}
	return 0, err
}

// query runs a read. A read may also be repeated when the connection failed,
// because it changes nothing: database/sql then takes another connection, and
// with MariaDB another node.
func (s *store) query(ctx context.Context, fn func() error) error {
	var err error
	for try := range maxTries {
		if try > 0 && !wait(ctx, try) {
			return ctx.Err()
		}
		if err = fn(); err == nil || (!s.d.Retry(err) && !s.d.Gone(err)) {
			return err
		}
	}
	return err
}

// put writes a row that may or may not be there. Neither MERGE nor ON
// DUPLICATE KEY is portable, so it is UPDATE first and INSERT when nothing
// matched. The driver counts matched rows, not changed ones (MariaDB gets
// ClientFoundRows for it), so writing the same values again counts as a hit
// and does not turn into an INSERT.
func (s *store) put(ctx context.Context, update string, updateArgs []any, insert string, insertArgs []any) error {
	return s.write(ctx, func(tx *sql.Tx) error {
		for round := range 2 {
			res, err := tx.ExecContext(ctx, update, updateArgs...)
			if err != nil {
				return err
			}
			n, err := res.RowsAffected()
			if err != nil {
				return err
			}
			if n > 0 {
				return nil
			}
			if round == 1 {
				return errors.New("sqlstore: the row is neither there nor addable")
			}
			if _, err := tx.ExecContext(ctx, insert, insertArgs...); err != nil {
				if !s.d.Duplicate(err) {
					return err
				}
				continue // somebody was faster: update that row instead
			}
			return nil
		}
		return nil
	})
}

// wait sleeps before the next try and reports whether the context is still
// alive.
func wait(ctx context.Context, try int) bool {
	d := pause << min(try, 6)
	d += time.Duration(rand.Int64N(int64(d)))
	t := time.NewTimer(d)
	defer t.Stop()
	select {
	case <-ctx.Done():
		return false
	case <-t.C:
		return true
	}
}

// TestEverySQLIsAConstant reads this package's own source and refuses any
// call that hands the database something other than a constant or a plain
// string: that is how "SQL only with placeholders" is kept, instead of
// trusting everyone to remember it.
func TestEverySQLIsAConstant(t *testing.T) {
	fset := token.NewFileSet()
	pkgs, err := parser.ParseDir(fset, ".", nil, 0)
	if err != nil {
		t.Fatal(err)
	}
	methods := map[string]bool{
		"ExecContext": true, "QueryContext": true, "QueryRowContext": true,
		"Exec": true, "Query": true, "QueryRow": true, "PrepareContext": true, "Prepare": true,
	}
	for _, pkg := range pkgs {
		for name, file := range pkg.Files {
			if strings.HasSuffix(name, "_test.go") {
				continue
			}
			ast.Inspect(file, func(n ast.Node) bool {
				call, ok := n.(*ast.CallExpr)
				if !ok {
					return true
				}
				sel, ok := call.Fun.(*ast.SelectorExpr)
				if !ok || !methods[sel.Sel.Name] || len(call.Args) == 0 {
					return true
				}
				// The SQL is the first argument, or the second when a context
				// comes first.
				arg := call.Args[0]
				if len(call.Args) > 1 && isCtx(arg) {
					arg = call.Args[1]
				}
				switch a := arg.(type) {
				case *ast.Ident: // a constant of this package
				case *ast.BasicLit:
					if a.Kind != token.STRING {
						t.Errorf("%s: the SQL is no string", fset.Position(a.Pos()))
					}
				default:
					t.Errorf("%s: the SQL is put together at run time", fset.Position(arg.Pos()))
				}
				return true
			})
		}
	}
}

func isCtx(e ast.Expr) bool {
	id, ok := e.(*ast.Ident)
	return ok && id.Name == "ctx"
}

package sqlstore

import (
	"context"
	"database/sql"
	"errors"

	"github.com/sorglos-it/nextgencloud/shared/dbapi"
)

const (
	onceInsert = "INSERT INTO ngc_once (kind, token, data, expires, used) VALUES (?, ?, ?, ?, ?)"
	onceUse    = "UPDATE ngc_once SET used = ? WHERE kind = ? AND token = ? AND used = ? AND expires > ?"
	onceRead   = "SELECT data FROM ngc_once WHERE kind = ? AND token = ?"
	onceState  = "SELECT used, expires FROM ngc_once WHERE kind = ? AND token = ?"
	oncePurge  = "DELETE FROM ngc_once WHERE expires <= ?"

	lockTake   = "UPDATE ngc_lock SET owner = ?, until = ? WHERE name = ? AND (owner = ? OR until <= ?)"
	lockInsert = "INSERT INTO ngc_lock (name, owner, until) VALUES (?, ?, ?)"
	lockFree   = "DELETE FROM ngc_lock WHERE name = ? AND owner = ?"
)

// OnceCreate is one INSERT, and that is what makes it atomic: the primary key
// decides. Of concurrent calls for the same kind and value exactly one gets
// the row; on Galera the losers see a certification conflict, repeat, and
// then find the row and give ErrUsed.
func (s *store) OnceCreate(ctx context.Context, kind string, value []byte, data string, expires int64) error {
	if kind == "" || len(value) == 0 || !okKey(kind) || len(value) > MaxKey || !okKey(data) {
		return dbapi.ErrInvalid
	}
	err := s.write(ctx, func(tx *sql.Tx) error {
		_, err := tx.ExecContext(ctx, onceInsert, []byte(kind), value, []byte(data), expires, int64(0))
		if err != nil && s.d.Duplicate(err) {
			return dbapi.ErrUsed
		}
		return err
	})
	return err
}

// OnceUse marks the value as used and gives back its data. The UPDATE does
// the deciding, so no SELECT ... FOR UPDATE is needed, which SQLite has not
// got anyway. It only changes a row that is neither used nor expired, so a
// second caller sees no change and then reads why.
func (s *store) OnceUse(ctx context.Context, kind string, value []byte, now int64) (string, error) {
	var data string
	err := s.write(ctx, func(tx *sql.Tx) error {
		res, err := tx.ExecContext(ctx, onceUse, int64(1), []byte(kind), value, int64(0), now)
		if err != nil {
			return err
		}
		n, err := res.RowsAffected()
		if err != nil {
			return err
		}
		if n > 0 {
			return tx.QueryRowContext(ctx, onceRead, []byte(kind), value).Scan(&data)
		}
		var used, expires int64
		switch err := tx.QueryRowContext(ctx, onceState, []byte(kind), value).Scan(&used, &expires); {
		case errors.Is(err, sql.ErrNoRows):
			return dbapi.ErrNotFound
		case err != nil:
			return err
		case used == 1:
			return dbapi.ErrUsed
		default:
			return dbapi.ErrNotFound // expired
		}
	})
	if err != nil {
		return "", err
	}
	return data, nil
}

func (s *store) OncePurge(ctx context.Context, now int64) error {
	_, err := s.exec(ctx, oncePurge, now)
	return err
}

// LockTake takes the lock unless somebody else holds it and their time has
// not passed. The UPDATE decides in one step - it changes the row only while
// the lock is free or already ours - so two owners can never both win. When
// it matches nothing the row may simply not be there yet; the INSERT tells
// the two apart, and its duplicate key means somebody else was faster.
func (s *store) LockTake(ctx context.Context, name, owner string, now, until int64) (bool, error) {
	if name == "" || owner == "" || until <= now || !okKey(name) || !okText(owner) {
		return false, dbapi.ErrInvalid
	}
	took := false
	err := s.write(ctx, func(tx *sql.Tx) error {
		took = false
		res, err := tx.ExecContext(ctx, lockTake, []byte(owner), until, []byte(name), []byte(owner), now)
		if err != nil {
			return err
		}
		n, err := res.RowsAffected()
		if err != nil {
			return err
		}
		if n > 0 {
			took = true
			return nil
		}
		if _, err := tx.ExecContext(ctx, lockInsert, []byte(name), []byte(owner), until); err != nil {
			if s.d.Duplicate(err) {
				return nil
			}
			return err
		}
		took = true
		return nil
	})
	if err != nil {
		return false, err
	}
	return took, nil
}

func (s *store) LockFree(ctx context.Context, name, owner string) error {
	_, err := s.exec(ctx, lockFree, []byte(name), []byte(owner))
	return err
}

func (s *store) UserPut(ctx context.Context, u dbapi.User) error {

			return err

			return dbapi.ErrInvalid

		}
		if n > 0 {
			return nil
		}

			blob(u.TOTP), u.Locked, int64(u.Failures), u.LastLogin)
		return err

// The four reading statements are constants of their own instead of one with
// switches inside: each one can use an index, and none is put together.
// Order is always (ts, id) descending, and the IDs are compared byte for
// byte, because they are 32 lower-case hex characters in a binary column.
const (
	logInsert = "INSERT INTO ngc_log (id, ts, user_id, kind, app, action, node, result_code, detail) " +
		"VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)"
	logCols   = "SELECT id, ts, user_id, kind, app, action, node, result_code, detail FROM ngc_log "
	logAll    = logCols + "ORDER BY ts DESC, id DESC LIMIT ?"
	logBefore = logCols + "WHERE ts < ? OR (ts = ? AND id < ?) ORDER BY ts DESC, id DESC LIMIT ?"
	logTime   = logCols + "WHERE ts < ? ORDER BY ts DESC, id DESC LIMIT ?"
	logUser   = logCols + "WHERE user_id = ? ORDER BY ts DESC, id DESC LIMIT ?"
	logUserBefore = logCols + "WHERE user_id = ? AND (ts < ? OR (ts = ? AND id < ?)) " +
		"ORDER BY ts DESC, id DESC LIMIT ?"
	logUserTime = logCols + "WHERE user_id = ? AND ts < ? ORDER BY ts DESC, id DESC LIMIT ?"
)

// LogAdd keeps one entry. The ID comes from the API and is the primary key,
// so the same ID twice is ErrUsed and nothing is written twice.
func (s *store) LogAdd(ctx context.Context, e core.LogEntry) error {
	if !core.ValidLogID(e.ID) || e.Kind == "" || e.Time <= 0 || !okKey(e.User) || !okKey(e.Kind) ||
		!okKey(e.App) || !okKey(e.Action) || !okKey(e.Node) || !okKey(e.Result) || !okText(e.Detail) {
		return dbapi.ErrInvalid
	}
	return s.write(ctx, func(tx *sql.Tx) error {
		_, err := tx.ExecContext(ctx, logInsert, []byte(e.ID), e.Time, []byte(e.User), []byte(e.Kind),
			[]byte(e.App), []byte(e.Action), []byte(e.Node), []byte(e.Result), []byte(e.Detail))
		if err != nil && s.d.Duplicate(err) {
			return dbapi.ErrUsed
		}
		return err
	})
}

// LogQuery returns a page, newest first. The cursor is (BeforeTime,
// BeforeID): with an ID the page starts inside that second, without one the
// whole second is left out, and without a time it starts at the newest entry.
func (s *store) LogQuery(ctx context.Context, q core.LogQuery) ([]core.LogEntry, error) {
	if q.Limit < 1 || q.BeforeTime < 0 || (q.BeforeID != "" && (!core.ValidLogID(q.BeforeID) || q.BeforeTime == 0)) ||
		!okKey(q.User) {
		return nil, dbapi.ErrInvalid
	}
	stmt, args := logAll, []any{int64(q.Limit)}
	switch {
	case q.User != "" && q.BeforeID != "":
		stmt = logUserBefore
		args = []any{[]byte(q.User), q.BeforeTime, q.BeforeTime, []byte(q.BeforeID), int64(q.Limit)}
	case q.User != "" && q.BeforeTime != 0:
		stmt, args = logUserTime, []any{[]byte(q.User), q.BeforeTime, int64(q.Limit)}
	case q.User != "":
		stmt, args = logUser, []any{[]byte(q.User), int64(q.Limit)}
	case q.BeforeID != "":
		stmt = logBefore
		args = []any{q.BeforeTime, q.BeforeTime, []byte(q.BeforeID), int64(q.Limit)}
	case q.BeforeTime != 0:
		stmt, args = logTime, []any{q.BeforeTime, int64(q.Limit)}
	}
	var out []core.LogEntry
	err := s.query(ctx, func() error {
		out = nil
		rows, err := s.db.QueryContext(ctx, stmt, args...)
		if err != nil {
			return err
		}
		defer rows.Close()

			var e core.LogEntry

			}

		}
		return rows.Err()
	})
	return out, err

import (

)

// New wraps an open file as a store. It creates nothing.
func New(db *sql.DB) dbapi.Store { return sqlstore.New(db, sqlstore.SQLite) }

// Open opens the file, brings the schema up to date and returns the store.
// The file belongs to whoever holds the key, so the migrations run here and
// need no separate account, unlike MariaDB. owner shows up in the migration
// lock, now is the time it records.
func Open(cfg config.DB, owner string, now int64) (dbapi.Store, error) {
	db, err := OpenDB(cfg)
	if err != nil {
		return nil, err
	}
	if _, err := migrate.Apply(context.Background(), db, sqlstore.SQLite, owner, now); err != nil {
		db.Close()
		return nil, err
	}
	return New(db), nil
}

// TestCAWorksWithTLSConfig makes the certificates the way ngc-db.sh does and
// proves that config.DB.TLSConfig accepts exactly them: the same CA, the
// node's own host name, TLS 1.3. If openssl builds something the Go side
// refuses, this fails here and not on the servers.
func TestCAWorksWithTLSConfig(t *testing.T) {
	if _, err := exec.LookPath("openssl"); err != nil {
		t.Skip("openssl fehlt")
	}
	dir := t.TempDir()
	cnf := filepath.Join(dir, "db-ca.cnf")
	body, err := os.ReadFile("../../templates/db-ca.cnf")
	if err != nil {
		t.Fatal(err)
	}
	const host = "db-1.ngc.test"
	if err := os.WriteFile(cnf, []byte(strings.ReplaceAll(string(body), "@HOST@", host)), 0o600); err != nil {
		t.Fatal(err)
	}
	run := func(args ...string) {
		t.Helper()
		cmd := exec.Command("openssl", args...)
		cmd.Dir = dir
		if out, err := cmd.CombinedOutput(); err != nil {
			t.Fatalf("openssl %v: %v\n%s", args, err, out)
		}
	}
	// The CA: Ed25519, as everywhere else in NGC.
	run("genpkey", "-algorithm", "ed25519", "-out", "ca.key")
	run("req", "-new", "-x509", "-key", "ca.key", "-out", "ca.crt", "-days", "7300",
		"-config", cnf, "-section", "ca_dn", "-extensions", "ca_ext")
	// The node makes its own key and only hands over the request.
	run("genpkey", "-algorithm", "ed25519", "-out", "node.key")
	run("req", "-new", "-key", "node.key", "-out", "node.csr", "-config", cnf, "-section", "node_dn")
	run("x509", "-req", "-in", "node.csr", "-CA", "ca.crt", "-CAkey", "ca.key", "-CAcreateserial",
		"-out", "node.crt", "-days", "3650", "-extfile", cnf, "-extensions", "node_ext")

	caPEM, err := os.ReadFile(filepath.Join(dir, "ca.crt"))
	if err != nil {
		t.Fatal(err)
	}
	db := config.DB{Driver: config.DriverMariaDB, Nodes: []string{host + ":3306"}, Name: "ngc",
		User: "ngc", Password: config.NewSecretText("x"), CA: string(caPEM)}
	if err := db.Validate(); err != nil {
		t.Fatalf("config refuses the CA of the template: %v", err)
	}
	clientCfg, err := db.TLSConfig(host)
	if err != nil {
		t.Fatal(err)
	}
	// A real handshake against a server that shows the node certificate.
	cert, err := tls.LoadX509KeyPair(filepath.Join(dir, "node.crt"), filepath.Join(dir, "node.key"))
	if err != nil {
		t.Fatal(err)
	}
	listener, err := tls.Listen("tcp", "127.0.0.1:0", &tls.Config{
		Certificates: []tls.Certificate{cert}, MinVersion: tls.VersionTLS13,
	})
	if err != nil {
		t.Fatal(err)
	}
	defer listener.Close()

	// Mit einem einzigen Accept blieb der zweite Dial dieses Falles ueber
	// 120 s stehen - der Fall HING, er fiel nicht. Und eine Frist allein

	// muss ein *tls.CertificateVerificationError sein, sonst beweist das
	// Scheitern nur, dass irgendetwas scheiterte.
	go func() {
		for {
			c, err := listener.Accept()
			if err != nil {
				return
			}
			c.(*tls.Conn).Handshake()
			c.Close()
		}
	}()
	dialer := &net.Dialer{}
	conn, err := tls.DialWithDialer(dialer, "tcp", listener.Addr().String(), clientCfg)
	if err != nil {
		t.Fatalf("the certificate of the node is refused: %v", err)
	}
	conn.Close()

	// The same certificate under another name must not be accepted.
	wrong, err := db.TLSConfig("db-2.ngc.test")
	if err != nil {
		t.Fatal(err)
	}
	if conn, err := tls.DialWithDialer(dialer, "tcp", listener.Addr().String(), wrong); err == nil {
		conn.Close()
		t.Error("a certificate for another host was accepted")
	}
}

// failPause is how long a node that refused a connection goes to the back of
// the line. Short enough that a node which comes back is used again soon,
// long enough that a dead node does not slow every connection down.
const failPause = 30 * time.Second

// picker decides which node a new connection goes to: round robin, so the
// load spreads over the Galera nodes, with a node that just failed at the
// back. It never drops a node, because all of them may be unreachable for a
// moment and the next try has to find them again.
type picker struct {
	mu    sync.Mutex
	count int
	next  int
	bad   []time.Time // when each node last refused, zero while it is fine
}

// order returns the nodes to try, best first.
func (p *picker) order(now time.Time) []int {
	p.mu.Lock()
	defer p.mu.Unlock()
	if p.bad == nil {
		p.bad = make([]time.Time, p.count)
	}
	// BERICHTIGT am 02.10.2026: ohne diesen Riegel teilt die Zeile
	// p.next = (p.next + 1) %% p.count bei count == 0 DURCH NULL, und damit
	// ist die Planzeile errors.New("mariadb: no node configured") weiter
	// unten unerreichbar. Gemessen vom Strang der Aufgabe 9 (Mutant M1).
	if p.count <= 0 {
		return nil
	}
	list := make([]int, p.count)
	for i := range list {
		list[i] = (p.next + i) % p.count
	}
	p.next = (p.next + 1) % p.count
	// A stable sort keeps the round robin among the nodes that are fine.
	sort.SliceStable(list, func(a, b int) bool {
		return p.resting(list[a], now) != p.resting(list[b], now) && !p.resting(list[a], now)
	})
	return list
}

// resting reports whether a node is still in its pause after a failure.
func (p *picker) resting(i int, now time.Time) bool {
	return !p.bad[i].IsZero() && now.Sub(p.bad[i]) < failPause
}

// failed records that a node refused a connection.
func (p *picker) failed(i int, now time.Time) {
	p.mu.Lock()
	defer p.mu.Unlock()
	if p.bad == nil {
		p.bad = make([]time.Time, p.count)
	}
	p.bad[i] = now
}

// works records that a node answered.
func (p *picker) works(i int) {
	p.mu.Lock()
	defer p.mu.Unlock()
	if p.bad != nil {
		p.bad[i] = time.Time{}
	}
}

// balancer is the driver.Connector database/sql asks for a connection. It
// hands the request to the next node that answers, so an API keeps working
// while one node is down.
type balancer struct {
	nodes  []driver.Connector
	pick   *picker

	driver driver.Driver
}

func (b *balancer) Driver() driver.Driver { return b.driver }

func (b *balancer) Connect(ctx context.Context) (driver.Conn, error) {
	var last error
	for _, i := range b.pick.order(b.now()) {
		conn, err := b.nodes[i].Connect(ctx)
		if err == nil {
			b.pick.works(i)
			return conn, nil
		}
		b.pick.failed(i, b.now())
		last = err
		if ctx.Err() != nil {
			break
		}
	}
	// BERICHTIGT am 02.10.2026, zwei Fehler in drei Zeilen, beide gemessen
	// (Strang der Aufgabe 9, Mutant M2):

	// 1. Die Zuweisung an `last` wurde NIE GELESEN - das `return` darunter
	//    legte einen neuen Fehler an und verwarf sie. Richtig ist ein
	//    eigenes `return` im Zweig.
	// 2. Der Text war DEUTSCH. Der Kommentar sagte "it goes into the log",

	//    englisch. Entschieden: englischer Fehlertext; deutsch wird erst

// Package mariadb opens the MariaDB Galera cluster of an NGC installation:
// every connection over TLS against the CA of the installation, spread over
// the nodes, with the next node taking over when one is down.
package mariadb

import (
	"database/sql"
	"database/sql/driver"
	"errors"
	"fmt"
	"net"
	"time"

	"github.com/go-sql-driver/mysql"

	"github.com/sorglos-it/nextgencloud/apps/server-db/classes/sqlstore"
	"github.com/sorglos-it/nextgencloud/shared/config"
	"github.com/sorglos-it/nextgencloud/shared/dbapi"
	"github.com/sorglos-it/nextgencloud/shared/trust"
)

// maxPacket has to be above the largest blob: a canonical ui-tar is at most
// store.MaxUITotal (64 MiB). The server is set to the same value
// (max_allowed_packet in templates/galera.cnf).
const maxPacket = 128 << 20

// OpenDB opens the cluster. It creates nothing: the schema comes from the
// migrations, and the ngc account may not create anything anyway.
func OpenDB(cfg config.DB) (*sql.DB, error) {
	if cfg.Driver != config.DriverMariaDB {
		return nil, fmt.Errorf("mariadb: driver %q, want %q", cfg.Driver, config.DriverMariaDB)
	}
	if len(cfg.Nodes) == 0 {
		return nil, errors.New("mariadb: no node in the configuration")
	}
	nodes := make([]driver.Connector, 0, len(cfg.Nodes))
	for _, node := range cfg.Nodes {
		c, err := connector(cfg, node)
		if err != nil {
			return nil, err
		}
		nodes = append(nodes, c)
	}
	db := sql.OpenDB(&balancer{
		nodes:  nodes,
		pick:   &picker{count: len(nodes)},
		now:    time.Now,
		driver: mysql.MySQLDriver{},
	})
	db.SetMaxOpenConns(16)
	db.SetMaxIdleConns(4)
	// A connection is retired after a while, so the load finds its way back
	// to a node that has come up again instead of sticking where it was.
	db.SetConnMaxLifetime(5 * time.Minute)
	db.SetConnMaxIdleTime(time.Minute)
	return db, nil
}

// connector builds the connector of one node. The TLS configuration comes
// from config.DB.TLSConfig with that node's host as the server name, so every
// node is checked against the CA of the installation and its own name.
func connector(cfg config.DB, node string) (driver.Connector, error) {
	if !trust.ValidHostPort(node) {
		return nil, fmt.Errorf("mariadb: %q is no host:port", node)
	}
	host, _, err := net.SplitHostPort(node)
	if err != nil {
		return nil, err
	}
	tlsCfg, err := cfg.TLSConfig(host)
	if err != nil {
		return nil, err
	}
	c := mysql.NewConfig()
	c.User = cfg.User
	c.Passwd = cfg.Password.Text()
	c.Net = "tcp"
	c.Addr = node
	c.DBName = cfg.Name
	c.TLS = tlsCfg // never a connection without a checked certificate
	c.AllowFallbackToPlaintext = false
	c.AllowAllFiles = false
	c.AllowCleartextPasswords = false
	c.AllowOldPasswords = false
	c.MultiStatements = false
	// The values never become part of the statement: the server prepares it
	// and gets the values on their own.
	c.InterpolateParams = false
	// An UPDATE has to report the rows it matched, not the ones it changed,
	// or writing the same values again would look like "no such row" - see
	// sqlstore.put and LockTake.
	c.ClientFoundRows = true
	c.CheckConnLiveness = true
	c.ParseTime = false // timestamps are numbers
	c.Loc = time.UTC
	c.MaxAllowedPacket = maxPacket
	c.Timeout = 5 * time.Second
	c.ReadTimeout = 60 * time.Second
	c.WriteTimeout = 60 * time.Second
	// The driver writes to stderr by default; NGC logs on its own and never
	// wants a driver message near a password.
	c.Logger = &mysql.NopLogger{}
	c.Params = map[string]string{
		// A read waits for what the cluster already took: an API that wrote a
		// session on one node has to find it on another one right away.
		"wsrep_sync_wait": "1",
		// Nothing is quietly cut or rounded.
		"sql_mode":  "'STRICT_ALL_TABLES,NO_ENGINE_SUBSTITUTION'",
		"time_zone": "'+00:00'",
	}
	return mysql.NewConnector(c)
}

// New wraps an open cluster as a store.
func New(db *sql.DB) dbapi.Store { return sqlstore.New(db, sqlstore.MariaDB) }

// Open opens the cluster and returns the store. It runs no migration: that is
// the job of the ngc_migrate account, which the API does not have.
func Open(cfg config.DB) (dbapi.Store, error) {
	db, err := OpenDB(cfg)
	if err != nil {
		return nil, err
	}
	return New(db), nil
}

	if migrateAccount {
		user, password = os.Getenv("NGC_DB_MIGRATE_USER"), os.Getenv("NGC_DB_MIGRATE_PASSWORD")

	return config.DB{
		Driver: config.DriverMariaDB, Nodes: strings.Split(nodes, ","),
		Name: os.Getenv("NGC_DB_NAME"), User: user,
		Password: config.NewSecretText(password), CA: string(ca),
	}

// fresh gives a subtest an empty schema. The migrate account applies the
// migrations once and then empties every table; no test creates a table.
func fresh(t *testing.T) dbapi.Store {
	t.Helper()
	admin, err := mariadb.OpenDB(clusterConfig(t, true))
	if err != nil {
		t.Fatal(err)
	}
	defer admin.Close()
	if _, err := migrate.Apply(ctx, admin, sqlstore.MariaDB, "test", time.Now().Unix()); err != nil {
		t.Fatal(err)

	for _, table := range sqlstore.Tables {
		if table == "ngc_schema" {
			continue // the record of the migrations stays
		}
		if _, err := admin.ExecContext(ctx, "DELETE FROM "+table); err != nil {
			t.Fatalf("%s leeren: %v", table, err)
		}
	}
	s, err := mariadb.Open(clusterConfig(t, false))
	if err != nil {
		t.Fatal(err)
	}
	return s

package migraterun

import (
	"context"
	"database/sql"
	"fmt"

	"github.com/sorglos-it/nextgencloud/apps/server-db/classes/mariadb"
	"github.com/sorglos-it/nextgencloud/apps/server-db/classes/sqlite"
	"github.com/sorglos-it/nextgencloud/apps/server-db/classes/sqlstore"
	"github.com/sorglos-it/nextgencloud/shared/config"
)

// open picks the driver from the configuration and gives back the dialect
// that belongs to it.
func open(cfg config.DB) (*sql.DB, sqlstore.Dialect, error) {
	switch cfg.Driver {
	case config.DriverMariaDB:
		db, err := mariadb.OpenDB(cfg)
		return db, sqlstore.MariaDB, err
	case config.DriverSQLite:
		db, err := sqlite.OpenDB(cfg)
		return db, sqlstore.SQLite, err
	}
	return nil, nil, fmt.Errorf("migrate: unbekannter Treiber %q", cfg.Driver)
}

// Run applies every missing migration and returns how many it applied. It is
// the whole of what ngc-api migrate does: one controller with role db starts
// it before the new API, with the migrate account from its controller.json.
func Run(ctx context.Context, cfg config.DB, owner string, now int64) (int, error) {
	db, d, err := open(cfg)
	if err != nil {
		return 0, err
	}
	defer db.Close()
	return Apply(ctx, db, d, owner, now)
}

// Needed reports whether anything is missing, without changing a thing. The
// API asks before it starts: a database that is behind means the update did
// not finish.
func Needed(ctx context.Context, cfg config.DB) (bool, error) {
	files, err := List()
	if err != nil {
		return false, err
	}
	db, _, err := open(cfg)
	if err != nil {
		return false, err
	}
	defer db.Close()
	level, err := Level(ctx, db)
	if err != nil {
		// No record of any migration means none ever ran.
		return true, nil
	}
	return level < files[len(files)-1].Version, nil
}
```

```go
package sqlite

import (
	"context"
	"database/sql"
	"fmt"
	"os"

	"github.com/sorglos-it/nextgencloud/shared/config"
)

// Backup writes a copy of the encrypted file to target. It opens the database
// only to hold everyone else off while it copies: a plain file copy of a
// database in use is half of two states.
//
// The copy is encrypted exactly like the original, with the same key from the
// configuration. Whoever keeps the backup has to keep that configuration
// somewhere else, or the copy can never be opened again - and whoever steals
// the backup alone has nothing.
func Backup(cfg config.DB, target string) error {
	db, err := OpenDB(cfg)
	if err != nil {
		return err
	}
	defer db.Close()
	ctx := context.Background()
	conn, err := db.Conn(ctx)
	if err != nil {
		return err
	}
	defer conn.Close()
	// One transaction that writes nothing but holds the write lock, so no
	// other writer changes a page while the bytes are read. The WAL is
	// folded into the file first, so the copy needs nothing beside it.
	if _, err := conn.ExecContext(ctx, "PRAGMA wal_checkpoint(TRUNCATE)"); err != nil {
		return err
	}
	tx, err := conn.BeginTx(ctx, &sql.TxOptions{})
	if err != nil {
		return err
	}
	defer tx.Rollback()
	if _, err := tx.ExecContext(ctx, "UPDATE ngc_schema SET step = step WHERE version = ?", int64(0)); err != nil {
		return err
	}
	body, err := os.ReadFile(cfg.Path)
	if err != nil {
		return err
	}
	// Write beside the target and rename, so a backup is never half a file.
	tmp := target + ".part"
	if err := os.WriteFile(tmp, body, 0o600); err != nil {
		return err
	}
	if err := os.Rename(tmp, target); err != nil {
		os.Remove(tmp)
		return fmt.Errorf("sqlite: die Sicherung ließ sich nicht ablegen: %w", err)
	}
	return nil
}
```

Die Anweisung `UPDATE ngc_schema SET step = step WHERE version = ?` trifft keine Zeile und ändert
nichts; sie ist nur da, damit SQLite mit `_txlock=immediate` die Schreibsperre wirklich hält.

- `ngc-db.sh backup <verzeichnis>`
  1. `mariadb-dump --single-transaction --skip-lock-tables --hex-blob --routines=FALSE --events=FALSE ngc`

     Kennwort fragt das Skript ab und schreibt es nirgendwohin.
  3. `sha256sum` daneben legen, das Arbeitsverzeichnis löschen, den Pfad ausgeben.
- `ngc-db.sh restore <datei>`
  1. Prüfsumme prüfen, entschlüsseln, den Inhalt auf die erste Zeile eines Dumps prüfen.
  2. Warnen, dass alles Vorhandene überschrieben wird, und ausdrücklich bestätigen lassen
     (bei `answer.yaml` über `restore_confirm: yes`).
  3. Mit dem Konto `ngc_migrate` einspielen, danach `migrate.Needed` über
     `ngc-api migrate` laufen lassen, damit das Schema zur eingesetzten API-Version passt.

## Offene Entscheidungen für den Koordinator

Nichts davon wird in diesem Plan einfach gemacht: Die Verträge sind eingefroren, und jeder Punkt
berührt entweder `shared/` oder einen anderen Teil.

1. **Wer spielt Migration 0001 bei der Installation ein?** Heute niemand. `ngc-db.sh` legt nur
   Datenbank und Konten an, `ngc-api` schreibt nur `api.json` und startet den Dienst, und der
   Controller mit Rolle `db` – der einzige mit dem Zugang `ngc_migrate` – wird erst nach der
   Ersteinrichtung gekoppelt. Die API kommt mit dem Konto `ngc` nicht an ein `CREATE TABLE`.
   **Vorschlag:** `ngc-api` bekommt in `answer.yaml` die drei Schlüssel `migrate_user`,
   `migrate_password` und `migrate_ca` nur für den Lauf von `install`, ruft damit einmal
   `ngc-api migrate` auf und schreibt sie **nicht** in `api.json`. Betrifft `shared/ulh.md` und
   den Teil API.
2. **Wie startet der Controller die Migrationen eines Updates?** Der Entwurf sagt nur, dass sie in
   `ngc-api` stecken und ein Controller mit Rolle `db` sie einspielt. **Vorschlag:**
   `ngc-api migrate --db <pfad>` mit dem Block `migrate` aus `controller.json` als JSON-Datei
   unter `/run/ngc/`, Modus 0600, vom Controller danach gelöscht; Rückgabe 0 = eingespielt,
   3 = nichts zu tun, sonst Fehlschlag mit einer deutschen Zeile auf stderr. Gehört in
   `shared/ulh.md`, betrifft API und Controller.
3. **Neue Schlüssel und Befehle für `ngc-db` in `shared/ulh.md`:** `ca_dir` (Pfad, in dem der
   private Schlüssel der CA liegt – gern ein Wechseldatenträger, der Schlüssel selbst kommt nie in
   `answer.yaml`), `restore_confirm`, dazu die Befehle `sign` (ein Knotenzertifikat aus einer
   Anfrage ausstellen), `backup` und `restore`. Dazu der Weg für weitere Knoten: Jeder Knoten
   erzeugt seinen Schlüssel selbst, zeigt nur die Anfrage, der Admin trägt sie zum ersten Knoten,
   `ngc-db.sh sign` gibt das Zertifikat zurück. Kein privater Schlüssel geht je über die Leitung.
4. **Portables DDL gibt es nicht wörtlich.** Oracle kennt kein `BIGINT` und kein `VARBINARY`,
   MSSQL kein `BLOB`. Der Plan löst das mit sechs Platzhaltern und einer festen Typtabelle je
   Datenbank (`{{key}}`, `{{text}}`, `{{doc}}`, `{{data}}`, `{{int}}`, `{{opts}}`); alles andere
   am SQL ist buchstäblich gleich. Entwurf 4.6 sagt „nur SQL, das alle fünf Systeme verstehen“ –
   bitte so protokollieren, damit Teilprojekt 4 weiß, woran es ist.
5. **`dbapi.Blob.Seq` ist `uint64`.** Keine der fünf Datenbanken hat eine portable vorzeichenlose
   64-Bit-Spalte. Der Plan lehnt Werte über 2^63−1 mit `ErrInvalid` ab. Entweder steht das künftig
   im Vertrag, oder das Feld wird `int64`.
6. **Keine Prüfung, ob die Datenbank erreichbar ist.** `shared/README.md` verlangt von der API
   `503 E_UNREACHABLE`, wenn die Datenbank nicht erreichbar ist, aber `dbapi` hat kein `Ping`.
   **Vorschlag:** `Ping(ctx context.Context) error` in `dbapi.Local`; sonst muss die API es aus
   beliebigen Fehlern raten.
7. **Der Schlüssel der MariaDB-Verschlüsselung liegt neben den Daten.** `file_key_management`
   braucht die Schlüsseldatei auf dem Knoten. Bis der Recovery-Modus das Datenbank-Volume mit
   LUKS2 und TPM absichert (`docs/recovery-modus.md`, Paket 5), liegt sie `root:mysql` mit Modus
   0400 auf dem Knoten. Bitte bestätigen oder den Recovery-Strang früher einplanen.
8. **Die vier Spalten des Recovery-Modus.** `docs/recovery-modus.md`, Abschnitt 1, verlangt in der
   Admin-Tabelle `erteilt_von`, `erteilt_am`, `laeuft_ab` und `signatur` als rückwärtskompatible
   Migration in `sql/`. Offen ist, wer die Migration schreibt (Recovery-Strang oder dieser Teil)
   und wie die deutschen Spaltennamen zur Regel „Bezeichner englisch“ passen. Ohne Entscheidung
   kommt sie in keiner der zwölf Aufgaben vor.
9. **80 MiB in einer Zeile.** Ein `dbapi.BlobUI` trägt das kanonische ui-tar, also bis zu
   `store.MaxUITotal` = 64 MiB. Deshalb `LONGBLOB`, `max_allowed_packet=128M` und
   `MaxAllowedPacket` im Treiber. Auf einem Pi ist das viel. Wenn Oberflächen besser neben der
   Datenbank liegen sollen, ist das eine Vertragsänderung an V4.

**1. Deckt der Plan die Aufgabe ab?** Jede Zeile aus `apps/server-db/CLAUDE.md` hat ihre Aufgabe:

Spalten des Recovery-Modus (offene Entscheidung 8) und wer bei der Installation migriert (1).

Aufgabe 7, Schritt 5 prüft mit `grep`, dass keine übrig bleibt.

`Retry`, `Duplicate`, `Exists`, `Gone`, `DDLInTx`), und genau die benutzen Aufgabe 3 (`Exists`,
`Duplicate`, `DDLInTx`, `Fill`), 4 (`Retry`, `Gone`, `Duplicate`), 5 (`Duplicate`) und 9.
